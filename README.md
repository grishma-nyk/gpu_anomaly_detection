AI-Driven Predictive Maintenance for GPU Clusters



Simulates GPU telemetry (temperature, GPU utilization, memory utilization, power ultilization), lets you inject custom anomalies with interactive sliders, and compares Logistic Regression, Random Forest, and LSTM models for failure prediction.



Setup

pip install -r requirements.txt



Run

Open in Jupyter Notebook or Google Colab, run the cell, adjust the sliders and click "Generate Data, Train \& Evaluate".
